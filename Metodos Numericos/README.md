 
# Disciplina a desplegar

**Mëtodos Numéricos para Ingeniería**

***

## Descripción

Disciplina cual permite análisis numérico en la resolución de problema de ingeniería, enfocado en modelos matemáticos que describen fenómenos naturales, cuales desempeños permiten visualizar mediante simulaciones y análisis de datos su comportamiento, entregando un entendimiento de su potencial como problema ingenieríl en la búsqueda de soluciones en las áreas de competencia.

## Propuestas

- Caso de Uso 1: Desarrollo numérico de un sistema masa resorte, usando modelo 2D cual desempeña el problema de un monorriel.

- Caso de Uso 2: Desarrollo numérico en la transferencia de calor de una placa irregular, usando modelo 2D mediante el uso de valores frontera con método de Dirichlet.

- Caso de Uso 3: Desarrollo numérico en la transferencia de calor de una aleta disipadora, usando modelo 3D mediante la ecuación de Laplace.

- Caso de Uso 4: Desarrollo numérico en la deforación de una placa cuadrada, usando modelo 3D mediante ecuaciones diferenciales parciales elípticas.
