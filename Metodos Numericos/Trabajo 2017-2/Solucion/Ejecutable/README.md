## Descripción de Datos

Dentro del directorio, se almacenan los archivos de ejecución Octave, cuales se detallarán a continuación.

- [Codigo.sh](https://github.com/DotPin/INFO290/blob/master/Metodos%20Numericos/Trabajo%202017-2/Solucion/Ejecutable/Codigo.sh): Código bash cual ejecuta todas las subrutinas de manera secuencial.

- [Dif_Divididas.py](https://github.com/DotPin/INFO290/blob/master/Metodos%20Numericos/Trabajo%202017-2/Solucion/Ejecutable/Dif_Divididas.py): Archivo python cual desempeña el algoritmo de diferencias divididas basada en la ecuaciones parciales elípticas.

- [desconposicion](https://github.com/DotPin/INFO290/blob/master/Metodos%20Numericos/Trabajo%202017-2/Solucion/Ejecutable/descomposicion.py): Archivo python cual desempeño es tomar tokens de polinomios generados por Dif_Divididas.py, para transformar en matrices numéricas.

- [GausSeidel.m](https://github.com/DotPin/INFO290/blob/master/Metodos%20Numericos/Trabajo%202017-2/Solucion/Ejecutable/GausSeidel.m): Archivo 1 Octave de resolución aproximada numéricamente de GausSeidel.

- [GausSeidel_2.m](https://github.com/DotPin/INFO290/blob/master/Metodos%20Numericos/Trabajo%202017-2/Solucion/Ejecutable/GausSeidel_2.m): Archivo 2 Octave de resolución aproximada numéricamente de GausSeidel.

- [cholesky_2](https://github.com/DotPin/INFO290/blob/master/Metodos%20Numericos/Trabajo%202017-2/Solucion/Ejecutable/cholesky_2.m): Archivo 1 Octave de resolución directa numéricamente de Cholesky


- [cholesky_3](https://github.com/DotPin/INFO290/blob/master/Metodos%20Numericos/Trabajo%202017-2/Solucion/Ejecutable/cholesky_3.m): Archivo 2 Octave de resolución directa numéricamente de Cholesky
