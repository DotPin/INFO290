# Presentación de caso 4.

**Cliente: Hidráulica, Aerospacial, Medicina, Construcción, Electrónica, Acústica, Informática, entre otras**

***

## Necesidad

Desafío implementar un diseño funcional a nivel matemático de un problema basado en la deformación de una placa, usando ecuaciones diferenciales parciales elípticas, que modelan un comportamiento de la deflexión de material rífgido con parámetros de rigidos que son sometidos a la elasticidad con razón de Poison, que para su aproximación, se usará el método de aproximación de diferencias divididas que permite conectar cada relación espacial numérica, su representación matricial permitirá ser resuelta mediante un método directo de sistema de ecuaciones multidimensional Cholesky y uno aproximado GausSeidel.
