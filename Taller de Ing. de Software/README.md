 # Disciplina a desplegar

**Taller de Ingeniería de Software**

***

## Descripción

Disciplina encargada para el trabajo en equipo en la realización de proyectos de software basados en alguna necesidad, orientados en su proceso de producción usando metodologías de desarrollo de software, usando los ciclos de vida correspondientes, para posteriormente proyectar dichos procesos hacia una implementación prototipable.

## Propuestas

- Caso de Uso 1: Proyecto EIMS, ERP Básico para gestión básica de inventario, proveedores y arriendo de materiales.
