## Necesidad

Mediante el uso de las tecnologías de la información, se ve la necesidad de generar una recopilación de herramientas digitales que permitan una mejor comprensión de las asignaturas que se cursan en las etapas educativas, permitiendo corresponder el conocimiento en aula, mediante herramientas digitales que lleven a la práctica prototipos de integración y primeros pasos hacia la tecnología mediante la base educativa.
