 # Disciplina a desplegar

**Taller de Construcción de Software**

***

## Descripción

Disciplina cual permite el modelamiento sobre problemas de ingeniería, cual diseño entreguen resultados esperados usando métodos matemáticos orientados a la simulación, donde dichas metodologías puedan ser aplicadas usando herramientas de programación existentes, sistematizando cada proceso de cálculo.
