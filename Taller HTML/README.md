 # Disciplina a desplegar

**Taller de HTML**

***

## Descripción

Disciplina encargada en el diseño y desarrollo para capas de software de tipo FrontEnd en conjunto con BackEnd (lijeras) cuales interactúan con lenguajes de programación como JavaScript, permitiendo crear maquetas y/o prototipos demostrativos para etapas de diseño o post implementación. 

## Propuestas

- Caso de Uso 1: Tutorial en uso de aplicación de diseño para imágenes
