 
# Disciplina a desplegar

**Sistemas de Información**

***

## Descripción

Disciplina cual permite la descripción y desglose de necesidad para elaboración de sistemas, donde cada proceso de elaboración de modelos para sus diseños sistemáticos, son generados a partir de requerimientos adquiridos por el negocio en cuestión. Los modelos aplicados o usados para la generación de sistemas entregan una idea de negocio cual proyecta funcionamiento en su estado natural, tras esto, su formulación mediante diagramas, sistematiza su funcionar para posteriores mejoras a nivel tecnológico.

## Propuestas

- Caso de Uso 1: Modelamiento de negocio para idea de sistematización.
