 
# Disciplina a desplegar

**Programación Orientada a Objetos**

***

## Descripción

Disciplina cual entrega el entendimiento de un paradigma de programación orientado del nivel empresarial, cual beneficio ayuda a como desplegar la información de manera estructurada, clasificada, relacionada entre otras prestaciones adicionales a nivel científico. 

## Propuestas

- Caso de Uso 1: Se solicita realizar un proyecto cual contemple un simple programa para edición de imágenes.
