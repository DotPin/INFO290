 
# Disciplina a desplegar

**Sistema de Gestión Estratégico**

***

## Descripción

Disciplina cual encarga de describir las diversas etapas de orden estratégicas de tipo organizacional, comprendiendo los conceptos de la competitividad corporativa para el diseño en sistemas de información para procesos continuos, permitiendo ordenadamente tomar ideas en tareas hacia planificaciones, cuales permitan mejoras y continuidad en el tiempo, entregando evaluaciones que se integren en las decisiones estratégicas de inversión empresarial.

## Propuestas

- Caso de Uso 1: Formulación y análisis estratégico de estudio educativo para "Codugemática".

- Caso de Uso 2: Análisis Estratégico y creación de valor para sector económico de Hotelería y Restaurantes.

- Caso de Uso 3: Análisis de modelado dimensional hacia pronóstico pandémico 2020.
