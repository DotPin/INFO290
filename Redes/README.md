 
# Disciplina a desplegar

**Redes**

***

## Descripción

Disciplina encargada de fundamentar todo proceso funcional de comunicación mediante estratégias tecnológicas, usando desde topologías, hasta aplicaciones basadas en enlaces, cual principio fundamental es el intercambio de información estandarizada basada en la data tanto generada como almacenada a nivel de infraestructura con arquitecturas sólidas.

## Propuestas

- Caso de Uso 1: Implementar un dispositivo conectado a internet que almacene los estados de un vehículo mediante protocolos IOT de tipo V2I.
