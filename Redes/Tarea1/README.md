# Presentación de caso 1.

**Cliente: Conductor, Servicios de Transporte, Desarrollador, Ingeniero Informático/Redes**

***

## Necesidad

Se necesita desarrollar mediante microcontroladores [ARDUINO](https://arduino.cl/), un sistema de infraestructura cual interacción es a base de estados vehiculares, capture información y sea enviada a una base de datos de tipo nube, donde los datos permitan ser guardados y obtenidos de manera remota, mientras el dispositivo captura en tiempo real la información de los estados del vehículo.
